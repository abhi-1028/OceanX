# 7–10 Minute SIH Demo Script

1. **Opening:** OceanX turns multidimensional ocean model and observation data into a browser-native digital twin.
2. **Login:** use `Team Apex Coders / SIH@2026`.
3. **Home:** show mission, regional windows and curated demo briefs.
4. **Global:** enter Digital Twin, rotate Earth, search/select Indian Ocean or Bay of Bengal.
5. **Scientific exploration:** switch temperature, salinity, chlorophyll and currents; change depth and time.
6. **Observations:** click `ARGO-BOB-001`, show profile and model-vs-observation metrics.
7. **Dive:** activate underwater mode and move through depth.
8. **AI:** show evidence-backed deterministic insight and limitations.
9. **Close:** emphasize browser-native interaction, provenance, NetCDF readiness and offline demo resilience.

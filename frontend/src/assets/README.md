# OceanX visual assets

- `earth-texture.png` — bundled offline fallback Earth base map used when the runtime Earth day-map cannot be loaded.
- `oceanx-logo.png` / `oceanx-mark.png` — OceanX branding assets.

The Digital Twin prefers the public Earth day/normal/specular/cloud planet assets used by the Three.js planet examples at runtime. The local Earth map remains available as the deterministic fallback.
